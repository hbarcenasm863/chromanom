🧪 Reacciones Orgánicas

Reacciones características de los grupos de hidrocarburos: esquema general, condiciones, ejemplos semi-desarrollados y práctica rápida.

Alcanos CₙH₂ₙ₊₂ Cicloalcanos CₙH₂ₙ
⚡ Sustitución Radical (SR)

Los alcanos y cicloalcanos son compuestos saturados; no reaccionan por adición. Su reacción típica es la sustitución homolítica, donde un H es reemplazado por otro átomo mediante radicales libres generados por luz (hν) o calor (Δ).

Halogenación SR · hν o Δ
▾
CₙH₂ₙ₊₂ + X₂ ──[hν / Δ]──→ CₙH₂ₙ₊₁X + HX (X = Cl, Br) Mecanismo: X₂ →[hν]→ 2 X• (iniciación) X• + R-H → R• + HX (propagación 1) R• + X₂ → R-X + X• (propagación 2)
Reactivo: X₂ (Cl₂ más reactivo; Br₂ más selectivo) Condición: luz UV (hν) o temperatura alta (Δ) Producto: haloalcano + ácido halógeno (HX)
📌 La selectividad aumenta en el orden: F₂ > Cl₂ > Br₂ > I₂
Ejemplos
CH₄ + Cl₂ →[hν] ──→ CH₃Cl + HCl clorometano
CH₃−CH₂−CH₃ + Br₂ →[hν] ──→ CH₃−CH(Br)−CH₃ + HBr Br al C2° (más selectivo)
🎯 Práctica rápida
¿Qué condición activa la halogenación radical de alcanos?
○ Calor moderado sin luz
○ Luz ultravioleta (hν) o temperatura alta
○ Catalizador ácido H₂SO₄
El producto de CH₄ + Cl₂ (hν) es:
○ CH₃OH + HCl
○ CH₃Cl + HCl
○ CH₂Cl₂ únicamente
Combustión completa Oxidación · O₂ exceso
▾
CₙH₂ₙ₊₂ + (3n+1)/2 O₂ ──→ n CO₂ + (n+1) H₂O Cicloalcanos: CₙH₂ₙ + 3n/2 O₂ ──→ n CO₂ + n H₂O
Condición: exceso de O₂ Productos: CO₂ + H₂O (gases; reacción exotérmica)
Ejemplos
CH₄ + 2 O₂ ──→ CO₂ + 2 H₂O metano
C₃H₈ + 5 O₂ ──→ 3 CO₂ + 4 H₂O propano
🎯 Práctica rápida
Los productos de la combustión completa de un alcano son:
○ CO + H₂O
○ CO₂ + H₂O
○ C + H₂O
¿Cuántos moles de O₂ necesita el propano (C₃H₈) para combustión completa?
○ 3
○ 4
○ 5
Combustión incompleta Oxidación · O₂ escaso
▾
CₙH₂ₙ₊₂ + O₂ (escaso) ──→ CO + H₂O (o C + H₂O) Grado de oxidación depende de la deficiencia de O₂: más O₂ → CO (monóxido, gas incoloro tóxico) menos O₂ → C (hollín, tizne)
Condición: deficiencia de oxígeno Señal: llama anaranjada/amarilla con humo negro
⚠️ El CO es incoloro, inodoro y tóxico — se une a la hemoglobina
Ejemplo
2 CH₄ + 3 O₂ ──→ 2 CO + 4 H₂O O₂ escaso → CO
🎯 Práctica rápida
La combustión incompleta produce principalmente:
○ CO₂ y H₂O
○ CO (y/o C) y H₂O
○ O₃ y H₂O
Apertura de anillo — Ciclopropano Adición · solo C₃
▾
Ciclopropano + HX ──→ propano halogenado Ciclopropano + H₂ ──[Ni/Δ]──→ propano
Solo el ciclopropano (anillo de 3C) reacciona por adición debido a la tensión angular extrema (60°, ángulo ideal 109.5°). Ciclobutano y superiores son estables.
📌 Los cicloalcanos de ≥4C reaccionan como alcanos (SR), no por adición
Ejemplo
c-C₃H₆ + HBr ──→ CH₃−CH₂−CH₂Br 1-bromopropano
🎯 Práctica rápida
¿Cuál cicloalcano puede reaccionar por adición para abrir el anillo?
○ Ciclohexano
○ Ciclopropano
○ Ciclopentano
Alquenos CₙH₂ₙ · doble enlace C=C
➕ Adición Electrofílica (AE)

El doble enlace C=C actúa como nucleófilo: la nube π dona electrones al electrófilo (E⁺). El nucleófilo (A⁻) se une al carbocatión intermedio. Regla de Markovnikov: el electrófilo va al carbono con más H (menos sustituido).

Hidrohalogenación AE · HX
▾
>C=C< + H−X ──→ −CH−CX− (X = Cl, Br, I)
Reactivo: HCl, HBr o HI Condición: temperatura ambiente, sin catalizador
📌 Markovnikov: H → C con más H | X → C con más sustituyentes
Ejemplos
CH₃−CH=CH₂ + HBr ──→ CH₃−CH(Br)−CH₃ Br al C2 (más sustituido)
CH₂=CH₂ + HCl ──→ CH₃−CH₂Cl cloroetano
🎯 Práctica rápida
CH₃−CH=CH₂ + HCl → ? (regla de Markovnikov)
○ CH₃−CHCl−CH₂Cl
○ CH₃−CHCl−CH₃
○ CH₃−CH₂−CH₂Cl
En la regla de Markovnikov, ¿a cuál carbono se une el halógeno (X)?
○ Al carbono con más hidrógenos
○ Al carbono con más sustituyentes (menos H)
○ Al carbono de menor peso molecular
Halogenación AE · X₂ · test Baeyer
▾
>C=C< + X₂ ──→ −CX−CX− (dihaluro vicinal) (X = Cl, Br)
Reactivo: Cl₂ o Br₂ (solución en CCl₄) Sin luz, sin calor — reacción espontánea a t° ambiente Estereoquímica: adición anti (trans)
🧪 Test de Baeyer: Br₂/CCl₄ (anaranjado) → decoloración = insaturación confirmada
Ejemplo
CH₃−CH=CH₂ + Br₂ ──→ CH₃−CH(Br)−CH₂Br 1,2-dibromopropano
🎯 Práctica rápida
¿Qué observación confirma un alqueno con el test de Baeyer (Br₂/CCl₄)?
○ El líquido se vuelve verde
○ El color anaranjado del Br₂ desaparece
○ Se libera gas
Hidrogenación (reducción) AE · H₂ · cat.
▾
>C=C< + H₂ ──[Ni / Pd / Pt]──→ −CH₂−CH₂− (alcano)
Reactivo: H₂ gas Catalizador: Ni (Raney), Pd/C o Pt (metales heterogéneos) Estereoquímica: adición sin (cis)
📌 Alqueno + H₂ → alcano (saturación completa del doble enlace)
Ejemplos
CH₃−CH=CH₂ + H₂ →[Ni] ──→ CH₃−CH₂−CH₃ propano
🎯 Práctica rápida
¿Qué tipo de compuesto se obtiene al hidrogenar un alqueno?
○ Alquino
○ Alcano
○ Alcohol
Hidratación (síntesis de alcoholes) AE · H₂O · H₂SO₄
▾
>C=C< + H₂O ──[H₂SO₄]──→ −CH−C(OH)− (alcohol)
Reactivo: H₂O (vapor) Catalizador: H₂SO₄ (ácido sulfúrico concentrado) Temperatura: 300 °C aprox.
📌 Markovnikov: OH → C más sustituido (menos H)
Ejemplos
CH₃−CH=CH₂ + H₂O →[H⁺] ──→ CH₃−CH(OH)−CH₃ propan-2-ol (Markovnikov)
CH₂=CH₂ + H₂O →[H⁺] ──→ CH₃−CH₂OH etanol
🎯 Práctica rápida
La hidratación de CH₃−CH=CH₂ con H₂SO₄ produce:
○ CH₃−CH₂−CH₂OH (propan-1-ol)
○ CH₃−CH(OH)−CH₃ (propan-2-ol)
○ CH₃−CO−CH₃ (propanona)
Ozonólisis Oxidación · O₃ → ruptura
▾
Paso 1 (ozonoide): >C=C< + O₃ ──→ molozonide → ozonoide Paso 2 (reductora): ozonoide + Zn/H₂O ──→ 2 aldehídos/cetonas Paso 2 (oxidante): ozonoide + H₂O₂ ──→ ácidos carboxílicos
El doble enlace se rompe por completo. Condiciones reductoras (Zn/H₂O) → aldehídos (C terminal) o cetonas. Condiciones oxidantes (H₂O₂) → ácidos carboxílicos.
📌 Útil para determinar la posición del doble enlace (análisis estructural)
Ejemplo
CH₃−CH=CH₂ + O₃ →[Zn/H₂O] ──→ CH₃CHO + HCHO etanal + metanal
🎯 Práctica rápida
La ozonólisis reductora de un alqueno CH₂=CH−CH₃ produce:
○ HCHO + CH₃CHO
○ CO₂ + H₂O
○ CH₃COOH + HCOOH
Prueba de Baeyer (KMnO₄) Oxidación · KMnO₄ frío
▾
Condiciones frías, diluidas: >C=C< + KMnO₄ (frío, dil.) ──→ diol (1,2-diol) + MnO₂↓ Condiciones calientes, concentradas: >C=C< + KMnO₄ (cal., conc.) ──→ ácidos / CO₂ (ruptura)
Permanganato de potasio: solución violeta/púrpura Resultado: decoloración (morado → incoloro/marrón) = insaturación MnO₂ precipitado marrón confirma reacción.
🧪 Test diferenciador: alquenos y alquinos dan (+), alcanos dan (−)
Ejemplo (condiciones frías)
CH₂=CH₂ + KMnO₄/H₂O ──→ HOCH₂−CH₂OH + MnO₂ etilenglicol
🎯 Práctica rápida
La prueba de Baeyer con KMnO₄ en frío da positivo cuando:
○ La solución se vuelve más violeta
○ La solución violeta se decolora (hay insaturación)
○ Se libera gas verde
Alquinos CₙH₂ₙ₋₂ · triple enlace C≡C
➕➕ Adición al triple enlace (×1 y ×2)

El triple enlace puede adicionarse una o dos veces: la primera adición convierte el alquino en un alqueno; la segunda adición convierte el alqueno en alcano (o derivado). Las mismas reacciones de alquenos aplican, con la posibilidad de doble adición.

Hidrohalogenación (×1 y ×2) AE · HX
▾
×1: −C≡C− + HX ──→ −CH=CX− (haloalqueno, Markovnikov) ×2: −CH=CX− + HX ──→ −CH₂−CX₂− (geminaldialuro)
Primera adición: forma haloalqueno (puede aislarse controlando estequiometría) Segunda adición: 1 mol más de HX → geminaldialuro (dos X en el mismo C)
📌 Markovnikov en cada paso. Segunda adición: X segundo al C ya halogenado
Ejemplos
CH≡CH + HBr (1 mol) ──→ CH₂=CHBr bromoetileno (×1)
CH≡CH + HBr (2 mol) ──→ CH₃−CHBr₂ 1,1-dibromoetano (×2)
🎯 Práctica rápida
La doble adición de HBr a CH≡CH produce:
○ CH₂Br−CH₂Br (1,2-dibromoetano)
○ CH₃−CHBr₂ (1,1-dibromoetano)
○ CH₂=CHBr
Halogenación (×1 y ×2) AE · X₂
▾
×1: −C≡C− + X₂ ──→ −CX=CX− (trans, dihaloalqueno) ×2: −CX=CX− + X₂ ──→ −CX₂−CX₂− (tetrahaloalcano)
Primera adición (×1): produce dihaloalqueno (geometría trans preferente) Segunda adición (×2): forma tetrahaloalcano vicinal
Ejemplo
CH≡CH + Br₂ (2 mol) ──→ CH₂Br−CHBr₂ → CHBr₂−CHBr₂ 1,1,2,2-tetrabromoetano
🎯 Práctica rápida
¿Cuántos moles de Br₂ se necesitan para llevar un alquino hasta tetrahaloalcano?
○ 1 mol
○ 2 moles
○ 3 moles
Hidrogenación (×1 Lindlar · ×2 total) AE · H₂ · cat.
▾
×1 (Lindlar): −C≡C− + H₂ ──[Pd/BaSO₄]──→ cis-alqueno ×2 (total): −C≡C− + 2H₂ ──[Ni/Pd]──→ alcano
Catalizador Lindlar (Pd/BaSO₄ + quinolina): selectivo → solo 1 adición → cis-alqueno Catalizador Ni/Pd sin envenenar: hidrogenación total → alcano
📌 Lindlar → cis (adición sin del mismo lado). Na/NH₃(l) → trans-alqueno
Ejemplos
CH≡CH + H₂ →[Lindlar] ──→ cis-CH₂=CH₂ etileno (×1)
CH≡CH + 2H₂ →[Ni] ──→ CH₃−CH₃ etano (×2)
🎯 Práctica rápida
El catalizador de Lindlar convierte un alquino en:
○ Trans-alqueno
○ Cis-alqueno
○ Alcano directamente
Hidratación (Markovnikov → cetona / aldehído) AE · H₂O · HgSO₄
▾
−C≡C− + H₂O ──[H₂SO₄/HgSO₄]──→ enol ──→ cetona (o aldehído) Alquino interno → cetona (tautomería ceto-enólica) Alquino terminal → aldehído (solo acetileno → acetaldehído)
Catalizador: H₂SO₄ / HgSO₄ (mercurio sulfato) Mecanismo: adición de agua → enol intermedio → tautomerización → carbonilo
📌 Markovnikov: OH al C más sustituido → cetona. Solo HC≡CH → CH₃CHO (aldehído)
Ejemplos
CH₃−C≡CH + H₂O →[H⁺/Hg²⁺] ──→ CH₃−CO−CH₃ propanona (cetona)
HC≡CH + H₂O →[H⁺/Hg²⁺] ──→ CH₃−CHO etanal (aldehído)
🎯 Práctica rápida
La hidratación de CH₃−C≡CH (propino) produce principalmente:
○ Un alcohol secundario
○ Una cetona (propanona)
○ Un aldehído primario
Acidez de alquinos terminales Propiedad ácida · pKa ≈ 25
▾
HC≡C−R + NaNH₂ ──→ NaC≡C−R + NH₃ HC≡C−R + NaOH ──→ NaC≡C−R + H₂O (bases fuertes) Alquinos terminales (H en C≡) son más ácidos que alcanos o alquenos: pKa: alcino terminal ≈ 25 / alqueno ≈ 44 / alcano ≈ 50
Solo alquinos TERMINALES (H unido al carbono del triple enlace) Alquinos internos: no tienen H en el triple enlace → no son ácidos
📌 El C(sp) tiene mayor carácter s → atrae más el par de electrones del enlace C−H → H más fácilmente disociable
Ejemplo
HC≡CH + NaNH₂ ──→ NaC≡CH + NH₃ acetiluro sódico
🎯 Práctica rápida
¿Cuál de los siguientes compuestos puede reaccionar con NaNH₂ por ser ácido?
○ CH₃−C≡C−CH₃ (but-2-ino, interno)
○ HC≡C−CH₃ (prop-1-ino, terminal)
○ CH₃−CH₃ (etano)
Aromáticos C₆H₅− · anillo de Hückel (4n+2 e⁻ π)
⚡ Sustitución Electrofílica Aromática (SEA)

El anillo bencénico es rico en electrones π (6 e⁻ deslocalidos). Reacciona con electrófilos fuertes (E⁺ generado por catalizador ácido de Lewis). A diferencia de alquenos, el producto es una sustitución (no adición) para mantener la aromaticidad.

Mecanismo general SEA: E⁺ + benceno → complejo σ (arenio, pierde aromaticidad) → −H⁺ → producto areno sustituido (recupera aromaticidad)
Halogenación SEA · X₂ · ácido de Lewis
▾
C₆H₆ + X₂ ──[FeBr₃ / AlCl₃]──→ C₆H₅X + HX Catalizador: FeBr₃ (para Br₂) o AlCl₃ (para Cl₂) Electrófilo generado: X⁺ (ión halonio) o X−FeX₃⁻
Sin catalizador NO reacciona (diferente a alquenos) Condición: ácido de Lewis activa X₂ → electrófilo X⁺
📌 SEA no necesita luz (diferencia clave con SR de alcanos)
Ejemplo
C₆H₆ + Br₂ →[FeBr₃] ──→ C₆H₅Br + HBr bromobenceno
🎯 Práctica rápida
¿Por qué el benceno necesita catalizador (FeBr₃) para halogenarse, pero el etileno no?
○ El anillo aromático es estable; necesita electrófilo más activo para reaccionar sin perder aromaticidad
○ El benceno es más reactivo y reacciona más fácil
○ El FeBr₃ aporta hidrógenos adicionales
Nitración SEA · HNO₃/H₂SO₄
▾
C₆H₆ + HNO₃ ──[H₂SO₄ conc.]──→ C₆H₅NO₂ + H₂O Electrófilo: ión nitronio NO₂⁺ (generado por H₂SO₄ + HNO₃) H₂SO₄ + HNO₃ → H₂NO₃⁺ → NO₂⁺ + H₂O
Mezcla nitrante: HNO₃ conc. + H₂SO₄ conc. (50-60 °C) Temperatura baja → monosustitución. Alta → di- o trinitración.
📌 El trinitrotolueno (TNT) se forma por triple nitración del tolueno
Ejemplo
C₆H₆ + HNO₃ →[H₂SO₄] ──→ C₆H₅NO₂ + H₂O nitrobenceno
🎯 Práctica rápida
El electrófilo activo en la nitración del benceno es:
○ NO₃⁻
○ NO₂⁺ (ión nitronio)
○ H₂SO₄
Sulfonación SEA · H₂SO₄ · reversible
▾
C₆H₆ + H₂SO₄ (conc. o fumante) ⇌ C₆H₅SO₃H + H₂O (ácido bencenosulfónico) Reversible (desulfonación): C₆H₅SO₃H + H₂O (calor) ⇌ C₆H₆ + H₂SO₄
Electrófilo: SO₃ (trióxido de azufre) — del H₂SO₄ fumante (oleum) Reacción reversible: útil en síntesis como grupo bloqueante temporal
📌 Única SEA reversible — el −SO₃H puede ser eliminado calentando en agua
Ejemplo
C₆H₆ + SO₃ →[H₂SO₄] ──→ C₆H₅SO₃H ácido bencenosulfónico
🎯 Práctica rápida
La sulfonación del benceno es la única SEA que es:
○ Irreversible
○ Reversible
○ Una reacción de adición
Alquilación de Friedel-Crafts SEA · RX · AlCl₃
▾
C₆H₆ + R−X ──[AlCl₃]──→ C₆H₅−R + HX (R = grupo alquilo; X = Cl, Br) Electrófilo: carbocatión R⁺ (o complejo RX·AlCl₃)
Catalizador: AlCl₃ (ácido de Lewis fuerte) Problema: el producto (alquilbenceno) es más reactivo → polialquilación Solución: exceso de benceno para minimizar polialquilación
📌 Limitación: reorganización del carbocatión (puede dar producto rearreglado)
Ejemplo
C₆H₆ + CH₃Cl →[AlCl₃] ──→ C₆H₅CH₃ + HCl tolueno (metilbenceno)
🎯 Práctica rápida
En la alquilación de Friedel-Crafts, el electrófilo activo es:
○ AlCl₃ directamente
○ El carbocatión R⁺ generado por AlCl₃ + RX
○ Cl⁻ (ión cloruro)
Acilación de Friedel-Crafts SEA · RCOCl · AlCl₃
▾
C₆H₆ + R−CO−Cl ──[AlCl₃]──→ C₆H₅−CO−R + HCl (arilcetona / fenilcetona) Electrófilo: acilio R−C≡O⁺ (catión acilio)
Catalizador: AlCl₃ (en exceso, ≥ 1 mol por mol de RCOCl) Reactivo: cloruro de acilo (RCOCl) o anhídrido (R(CO)₂O) Ventaja sobre alquilación: NO hay poliacilación (el grupo C=O desactiva el anillo)
📌 Mejor que alquilación para obtener monosustituido limpio
Ejemplo
C₆H₆ + CH₃COCl →[AlCl₃] ──→ C₆H₅COCH₃ + HCl acetofenona
🎯 Práctica rápida
La acilación de Friedel-Crafts no sufre poliacilación porque:
○ El AlCl₃ se consume en la primera etapa
○ El grupo −C=O incorporado desactiva el anillo para electrófilos
○ La reacción es reversible
